# Research Manifest Template

Use this template for targeted external references under `References/research/<topic>_<date>/MANIFEST.md`.

```yaml
topic:
date:
reason:
trigger_phase:
sources:
  - title:
    url_or_path:
    license_if_visible:
    relevance:
what_was_learned:
what_was_reused:
what_was_not_reused:
risks:
next_action:
```

Rules:

1. Prefer official MWORKS/Tongyuan/MoHub material first.
2. Open-source projects are references, not copy-paste competition submissions.
3. Do not overwrite official materials or model files with crawled content.
4. Save source code only when it is clearly needed; otherwise save notes and links.
