# 架构

## 1. 系统分层

```text
Official UGV model
  -> sensors and vehicle dynamics
  -> path planning baseline
  -> obstacle avoidance controller
  -> control allocation
  -> Ackermann PID actuator control
  -> scoring and visualization
```

## 2. 主要模块

| 模块 | 路径 | 当前角色 |
|---|---|---|
| Example | `Models/UGV/Example/` | 赛道示例入口。 |
| ObstacleAvoidanceController | `Models/UGV/Control/ObstacleAvoidanceController/` | 参赛者主要建模目标。 |
| PathPlanning | `Models/UGV/Control/PathPlanning/` | 官方循迹/路径规划基线。 |
| ControlAllocate | `Models/UGV/Control/ControlAllocate/` | 平衡路径规划与避障输出。 |
| Ackermann_control | `Models/UGV/Control/Ackermann_control/` | 期望速度/转角到底层车辆控制。 |
| Sensors | `Models/UGV/Vehicle/Sensors/` | 前后左右距离计算。 |
| Road / saidao | `Models/UGV/Road/`, `Models/UGV/saidao/` | 道路与正式赛道。 |
| CountPoint | `Models/UGV/CountPoint/` | 碰撞计数和避碰得分。 |

## 3. 控制接口

避障控制器：

```text
Models/UGV/Control/ObstacleAvoidanceController/ObsAvoidController_Sysblock2.mo
```

输入：

| 输入 | 含义 |
|---|---|
| `front_dist` | 前方距离。 |
| `rear_dist` | 后方距离。 |
| `left_dist` | 左侧距离。 |
| `right_dist` | 右侧距离。 |

输出：

| 输出 | 含义 |
|---|---|
| `speed` | 避障控制器建议期望车速。 |
| `steer` | 避障控制器建议期望转向。 |

## 4. 推荐算法路线

第一版采用可解释、可调参、适合 Sysblock 的规则控制：

1. 巡航：无近障碍时输出稳定巡航速度和近零避障转角。
2. 前向避障：前方距离低于阈值时降低速度，并根据左右距离差选择转向。
3. 侧向避障：左右距离低于阈值时施加反向转角。
4. 紧急处理：距离过小则强制降速或倒车，并输出较大避让转角。
5. 平滑/限幅：限制速度和转角突变，避免导致底层 PID 或车辆模型振荡。

第二版再考虑势场、状态机、曲率感知、速度自适应等增强。

## 5. 证据流

```text
model version
  -> track name
  -> simulation run
  -> time/collision/score extraction
  -> screenshot/log/manifest
  -> report figure/table
```

不要用单张截图替代指标；不要用模型能翻译替代赛道完成。
