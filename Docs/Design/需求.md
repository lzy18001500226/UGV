# 需求

## 1. 功能需求

1. 读取官方无人车模型的距离传感器信息。
2. 基于前、后、左、右距离设计避障策略。
3. 输出期望车速和期望转向。
4. 在官方 4 条初赛赛道上完成一圈行驶。
5. 尽量减少道路碰撞和障碍碰撞。
6. 在避碰基础上尽量缩短完成时间。
7. 生成可复现的仿真结果、指标和报告材料。

## 2. 非功能需求

1. 算法逻辑清晰，参数可解释。
2. 模型修改范围小，优先只修改避障控制器。
3. 仿真结果可复现，报告中能说明模型、参数、赛道和结果来源。
4. 控制逻辑应尽量适合后续 MWORKS 代码生成和实物小车迁移。

## 3. 当前实现边界

默认不修改：

```text
Models/UGV/Vehicle/

Models/UGV/Example/

```

如必须修改默认不修改区域，应先形成原因、影响、回滚方式和用户确认。

## 4. 最小验收

第一阶段最小验收：

1. 官方模型可加载。
2. 基线示例可定位并记录。
3. 避障控制器接口明确。
4. 至少一条正式赛道可运行并产出时间、碰撞和得分证据。

完整初赛验收：

1. 4 条正式赛道均有运行证据。
2. 每条赛道均记录行驶时间、道路碰撞数、障碍碰撞数、避碰得分。
3. 有可复现参数表。
4. 有仿真报告草稿和最终版。
