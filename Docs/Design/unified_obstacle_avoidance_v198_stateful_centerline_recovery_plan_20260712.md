# v198 统一避障候选：目标航向等价角连续化

## 目的

在保持 v148 前方避障权威和四赛道统一算法约束的前提下，消除
`atan2` 目标航向跨越 `-pi/pi` 时对 Ackermann 航向环造成的非物理跳变。

## 证据依据

- v148 Track3 在 `T=21.1` 发生早停，车辆命令出现不可行尖峰。
- v197 的离散航向斜率限制只把早停推迟到 `T=70.65`，没有完成赛道，已拒绝。
- `purePursuitControl` 返回全局目标航向 `atan2(ty-y, tx-x)`；当前分配器把它
  与避障偏置线性相加后直接送入航向环，没有选择连续的 `2*pi` 等价角。
- Track3 诊断中目标航向跳变同时伴随约 `36.84 rad/s` 的航向环输出尖峰和
  后轮速度数量级跳变，符合角度跨界被当作真实大误差的特征。
- `References/research/steering_authority_wall_following_20260710/` 要求安全层
  高于路径跟踪层，同时采用有界输出和状态连续性。

## 候选语义

1. 保留 v148 的路径航向、避障偏置、速度和状态机语义。
2. 对二者相加后的目标航向，选择距离上一采样目标最近的 `2*pi` 等价角。
3. 该变换不改变物理方向，不做斜率限制，不压缩正常转向幅值。
4. 不得按赛道、时间、绝对坐标或分数分支，也不得修改官方车辆模型。
5. 只有同时满足官方 `SimulateModel=false`、`T>10`、`distanceSensor1.d<0.02`
   才算完成；延长运行时间或可读的 `P` 不能替代完赛。

## 实现边界

- 允许修改：选手控制器/分配链中已有的避障状态与路径回归逻辑。
- 禁止修改：`Models/UGV/Vehicle/`、`Road/`、`saidao/`、`CountPoint/`、`Example/`、
  `References/official_materials/` 和官方评分逻辑。
- 不重复测试：单纯速度上下限、航向增益、斜率限制、固定入口偏置、同类 OA 标量衰减。

## 验收顺序

1. 静态 deployability checker 和 `python -m pytest Scripts\\tests -q`。
2. Track3 1 s plain `SimulateModel` gate。
3. Track3 长跑 plain `SimulateModel`，确认官方完赛条件及 `T/cR/cO/P`。
4. Track3 未完赛、早停或分数无收益则准确回滚 v148，并写结果包。
5. 只有 Track3 完赛后，才扩展同一候选到四赛道。

## 当前结论

本文只是 v198 设计门，不代表实现、完赛或分数收益。若恢复逻辑不能同时保持
前方安全权威和终点中心线收敛，候选必须拒绝，不得用包装变量或固定时间窗宣称成功。
